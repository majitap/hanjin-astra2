# 한진개발 — Astra 2

운영 주소: https://majitap.github.io/hanjin-astra2/

빌드가 필요 없는 반응형 정적 사이트입니다. GitHub Pages에서 main 브랜치 루트를 배포합니다.

- index.html: 회사소개, 서비스, 진행 절차, 연락처, 문의 폼
- styles.css: 8px 여백 체계, 한글 자간 0.08em, 모바일 및 모션 감소 대응
- script.js: 메뉴, 영상 재생, 서비스 선택, 접근 가능한 문의 창
- email.js: 기존 Web3Forms 전송 및 오류 처리

폰트: 네이버 나눔스퀘어 네오 (공식 CDN). https://hangeul.naver.com/font
영상: 기존 한진개발 사이트의 Pexels 영상. Sururi Ballıdağ, https://www.pexels.com/video/28823325/

문의 전송은 원본 사이트의 공개 Web3Forms 폼 ID를 유지합니다. 폼 관리 설정에서 수신 주소를 관리합니다. 도메인 제한이 있는 경우 배포 도메인을 허용해야 합니다. 비밀번호나 비밀 API 키는 포함하지 않습니다.
